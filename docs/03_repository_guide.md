# 3. Repository guide

## Top level

| Path | What it is |
|---|---|
| `Neural_Nexus_Final.pdf` | The final proposal |
| `plan.md` | Stage-by-stage plan with owners |
| `specs.md` | Specification of the finished Stage 0–1 work and of Stage 2 |
| `README.md` | Short setup and command list |
| `src/dpdp_audit/` | The Python package. All logic lives here |
| `scripts/` | Command-line entry points that call the package |
| `data/` | Small derived data kept in git. Big downloads go to `data/raw/` and `data/external/`, which are ignored |
| `outputs/` | Results: saved runs, scores, the PoliCheck smoke-test output |
| `kaggle/b1b2/` | The Kaggle GPU job that runs B1/B2 on Qwen |
| `notebooks/` | An interactive Kaggle notebook for Qwen (generated by `make_notebooks.py`) |
| `tests/` | `pytest` tests (35) |
| `docs/` | These pages |

## How the pieces connect

```
OPP-115 annotations ──► opp115.py ──► split.py (80/35)
                                       │
                                       ▼
                         gold_rules.py (answer-key rules)
                                       │
                 cells.py (what each policy can host) ──► generator.py
                                                           │
                         data/benchmark/main/  ◄───────────┘
                         (cases + answer_keys)
                            │            │
              export_policheck.py     baselines.py ◄── tools/ (app readers)
                            │            │           ◄── retrieval.py (DPDP index)
                     PoliCheck (Docker)  │           ◄── llm.py (Qwen / Gemini)
                            │            ▼
                      tool_runs.py   outputs/runs/
                            └──────────┬─┘
                                       ▼
                                   score.py ──► outputs/scores/main.json
```

## The package `src/dpdp_audit/`

| Module | Job |
|---|---|
| `paths.py` | Locations of `data/`, `data/raw/`, `outputs/` |
| `opp115.py` | Loads OPP-115 policies (as paragraphs) and their consolidated annotations |
| `split.py` | Makes and loads the 80/35 policy split (seed 13) |
| `dpdp_text.py` | Splits the Act and Rules text into citable units |
| `gaps.py` | Gap types, levels, labels, and the gap-to-section table |
| `retrieval.py` | bge-small embeddings + FAISS search over DPDP units (thread-safe loading) |
| `tools/` | `parse_deps` (gradle/npm/pip dependencies → SDKs), `parse_perms` (Android permissions → data types), `get_flows` (`dataflows.json`), `lookup_sdk`, `search_policy` (TF-IDF over paragraphs) |
| `gold_rules.py` | The scripted answer-key rules |
| `cells.py` | Lists every gap a policy could host and its level |
| `generator.py` | Builds controls, variants, app files and answer keys |
| `cases.py` | Reads cases and answer keys from disk |
| `export_policheck.py` | Writes cases in PoliCheck's input format |
| `tool_runs.py` | Runs PoliCheck in Docker and converts its output back to our format |
| `llm.py` | LLM client for Gemini or any OpenAI-compatible server (vLLM), with on-disk caching |
| `baselines.py` | The B1/B2 prompts and reply parsing |
| `runs.py` | Where runs are saved: `outputs/runs/<split>/<system>/seed<k>/<case>.json` |
| `score.py` | All metrics and the policy-level bootstrap |

## Data files kept in git

| File | Contents |
|---|---|
| `data/splits.json` | Which 80 policies train, which 35 are held out |
| `data/dpdp/sections.jsonl` | 153 DPDP units (`id`, `title`, `text`) |
| `data/dpdp/gap_to_section.csv` | Gold and accepted citations per gap type |
| `data/tools/sdk_table.csv` | 20 SDKs: vendor, category, ad/tracking flag, gradle/npm/pip names |
| `data/tools/datatype_mapping.csv`, `sdk_domains.csv` | How our data types and SDKs map to PoliCheck's vocabulary |
| `data/benchmark/cell_counts.csv` | How many held-out policies can host each gap type × level |
| `data/benchmark/main/cases/<id>/` | One test case: `policy.txt`, `meta.json`, `app/` |
| `data/benchmark/main/answer_keys/<id>.json` | Its answer key |
| `data/benchmark/main/export/policheck/` | The same cases in PoliCheck format, plus `coverage.json` |
| `data/benchmark/main/summary.json` | Counts of cases, planted gaps, findings and labels |

## Outputs kept in git

| File | Contents |
|---|---|
| `outputs/runs/main/B1/`, `B2/` | 306 saved runs each (102 cases × 3 seeds) |
| `outputs/runs/main/S1/` | PoliCheck's converted output for the 2 smoke-test cases |
| `outputs/scores/main.json` | All scores, per seed, with bootstrap intervals |
| `outputs/stage0_model_check.json` | Proof that Qwen answered on Kaggle with log-probabilities |
| `outputs/tools/policheck/main/policheck_results.csv` | PoliCheck's raw smoke-test output |

Ignored and local only: `outputs/cache/` (LLM replies and the FAISS index), `outputs/logs/` and the Kaggle
download/upload folders.
